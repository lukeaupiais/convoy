# Security policy

Convoy is a pre-release project. We review security reports against the current
`main` branch. There is no versioned release with a security support commitment.

Report a potential vulnerability privately through the repository's
[Security tab](https://github.com/lukeaupiais/convoy/security) by choosing
**Report a vulnerability**. Private vulnerability reporting is enabled. Please
do not put exploit details or real credentials in a public issue or pull request.

Include the affected commit, impact, reproduction steps, and any relevant
configuration. For ordinary bugs and feature requests, use GitHub Issues.
